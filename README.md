# Similar coupling-strength trends mask divergent vegetation–moisture timescale shifts

## 1. System requirements

Operating system: Windows 64-bit  
Python version: 3.11.11  
Python distribution: Anaconda

## 2. Environment

The code was prepared and checked using Python 3.11.11 with Anaconda on a 64-bit Windows system. Notebooks can be opened in Jupyter Notebook, JupyterLab, or Visual Studio Code with Jupyter support.

Required packages and version numbers are listed in `requirements.txt`. No specialized hardware or GPU is required.

## 3. Installation guide

Install the required packages using:

```bash
python -m pip install -r requirements.txt
```

Start JupyterLab using:

```bash
jupyter lab
```

Installation time depends on the network connection and packages already installed. Cartopy uses Natural Earth coastline and boundary files; it may download them when first used.

## 4. Demo data

The complete study compares SPEI–SIF and SSMIrz–SIF relationships across four seasons, four climate zones, and two response metrics, Rmax and Ts. The revised analysis uses accumulation timescales of 1–24 months and eleven overlapping ten-year windows from 2001–2010 to 2011–2020.

The included seasonal and climate-zone examples use spring (MAM) and the Temperate region. Each figure folder contains the corresponding notebook and its input files in `Inputs/`.

The examples include:

- NetCDF trend fields, selected correlations, optimal timescales, and significance fields for spatial figures.
- CSV area-share and trend tables for Fig. 2.
- Excel predictor-ranking tables for Fig. 3.
- Saved SHAP values, feature values, predictor importances, and partial-dependence curves for Fig. 4.
- Frequency arrays, event matrices, and fixed-scale partial-correlation fields for the supplementary figures.
- Prepared monthly SIF, SPEI, and SSMIrz files for the correlation-analysis example.
- Predictor and response samples for the random-forest and SHAP analysis.

## 5. Demo

To run a figure example:

1. Install the packages listed in `requirements.txt`.
2. Open the corresponding folder, for example `Figure/Fig.3/`.
3. Open `Fig.3.ipynb` in Jupyter Notebook, JupyterLab, or Visual Studio Code.
4. Run the notebook cells in order.
5. Inspect the generated files in that folder's `Outputs/` directory.

Each drawing notebook contains its required functions and reads the files in its own `Inputs/` directory. No project-specific Python helper script or other figure notebook is needed to run it.

Expected output: the figures corresponding to the included input files, together with supporting plotting tables where applicable. Raster figures are saved at 600 dpi; PDF outputs are also generated by the relevant notebooks.

All 22 drawing notebooks were executed using their supplied inputs. Individual examples took approximately 3–50 seconds in the validation environment. Runtime depends on the computer, installed fonts, and input size.

## 6. Instructions for use

The code is organized by figure and key analysis step.

To use other data:

1. Prepare inputs with the variable names, table columns, dimensions, and coordinates expected by the selected notebook.
2. Place them in the corresponding `Inputs/` directory, or update the input locations in the notebook.
3. Set the desired season, climate zone, and other plotting parameters.
4. Run the cells sequentially and save the generated figures.

Input and output locations are relative to each notebook folder. Source code is in English and notebook outputs have been cleared.

## 7. Key analysis notebooks

### `Data Processing/Rmax_Ts.ipynb`

This notebook calculates pixel-wise Spearman correlations between SIF and SPEI or SSMIrz, separately for each calendar month and accumulation timescale. It reads prepared monthly inputs with calendar-month preprocessing and full-period linear detrending already applied.

Each correlation uses ten paired same-month observations across the years in a ten-year window. Within each season, the coefficient with the largest absolute magnitude is selected from three calendar months multiplied by 24 timescales. The outputs retain its absolute magnitude (`max_abs_r`, Rmax), signed value (`max_r`, Ropt), corresponding accumulation timescale (`opt_scale`, Ts), and calendar month (`opt_month`). The original candidate traversal is retained for resolving ties.

The supplied input files support a spring example over all eleven moving windows. The notebook also checks the numerical results against scalar SciPy calculations.

### `Data Processing/SSMIrz.ipynb`

This notebook constructs SSMIrz from monthly GLEAM root-zone soil moisture. It merges the annual monthly files, calculates complete trailing-window means at accumulation timescales of 1–24 months, and transforms the resulting series to standard-normal quantiles separately for each grid cell, calendar month, and timescale.

The empirical reference distribution uses observations from 2001–2020. Data preceding 2001 support construction of the trailing windows and do not enter the reference-period ranking. Input windows include the current month, and no additional one-month shift is applied.

The original monthly SMrz files for this preprocessing step are supplied separately by the data provider and are not included in the archive. They should be placed under `Data Processing/Inputs/SMrz_monthly/` before running this notebook.

### `Data Processing/RF_SHAP.ipynb`

This notebook reads the prepared predictor and trend-response table after initial significance screening. The included table uses the original spring, Temperate, SPEI–SIF Rmax analysis cohort. It applies average-linkage clustering to Spearman distances (1 minus the absolute correlation), cuts clusters at 0.7 absolute correlation, and retains the predictor with the highest average within-cluster absolute correlation.

A random forest with 300 trees and random seed 42 is fitted to the retained predictors. The notebook exports impurity-based predictor importance, SHAP contributions for up to 800 sampled pixels, and partial-dependence curves for the twelve highest-ranked predictors. SHAP values are checked against the model predictions.

The stability analysis uses 500 pixel-bootstrap replicates, sampling the same number of pixels with replacement at each replicate. Predictor selection is fixed across replicates. Original top-three predictors are retained when they appear in the top three in at least 60% of replicates. Checkpoints are saved every 50 replicates, allowing an interrupted run to resume. The bootstrap sampling seed is 20261009.

Run the cells in order. Analysis results are written to `Data Processing/Outputs/RF_SHAP/`. The exported `importance.csv`, `shap_values.csv`, `feature_values.csv`, and `plot_settings.json` can be used by the Fig. 4 drawing notebook after copying them to its `Inputs/` folder. The supplied Fig. 4 inputs remain the original saved analysis results.

## 8. Reproducibility notes

The figure notebooks plot saved analysis outputs. In particular, Fig. 4 reads the saved SHAP and partial-dependence results; running this drawing example does not refit the random forest.

Rmax is the maximum absolute correlation, whereas Ropt retains the original sign of the selected coefficient. The figure code distinguishes these quantities according to the variable being displayed.

The computational supplementary figures are supplied separately as Figs. S1–S10 and S13–S20. Figs. S11 and S12 are workflow diagrams and do not have numerical plotting notebooks.
